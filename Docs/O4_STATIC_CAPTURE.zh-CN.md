# 静态姿势采集

当前流程是“摆好人偶，点击采集，确认稳定后写入一个姿势”。当前使用说明以 [README_PoseDoll.md](../README_PoseDoll.md) 为准。

## 操作

1. 打开目标角色所在关卡和顶层 Level Sequence，绑定角色与序列。
2. 连接静态人偶，选择全身或需要替换的部位。
3. 摆好人偶，将 Sequencer 播放头停在目标帧，点击“采集”。
4. 插件发起带请求 ID 的稳定采样，检查完整性、校准身份与稳定性，通过后只写入一次。
5. “采集并前进”在成功写入后移动播放头；下一姿势仍需再次点击。
6. 等待期间改动角色、序列、播放头、范围，断开连接或执行撤销、重做，会自动取消当前请求。迟到回复不能覆盖后来的编辑。

采集完成后可继续手工编辑 Control Rig。角色放置沿用 UE 原有变换轨道，插件只替换所选关节的相对转角。

## 稳定采样

活动采样约 10 Hz，带少量周期抖动；单次完整扫描不超过 100 ms。至少 6 次扫描，所有轴共同覆盖至少 500 ms；峰峰值不超过 0.30°，回归漂移不超过 0.20°/s。最终扫描年龄上界为 200 ms，请求总超时为 3 s。

这些是初始软件参数，尚非实物验收数据。请求期间的多次读取用于确认静止，最终结果始终是单个完整快照。
